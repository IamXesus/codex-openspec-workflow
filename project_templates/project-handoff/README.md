# Project handoff

This directory is the integrated, repository-owned source of current project context for people and agents.

## Reading order

1. `AGENTS.md`
2. `docs/project-handoff/README.md`
3. `docs/project-handoff/project-audit.md`
4. The affected business, integration, architecture, and open-issue documents in this directory
5. Current normative behavior in `openspec/specs/`
6. Applicable unarchived deltas in `openspec/changes/`
7. Archived rationale in `openspec/changes/archive/`
8. Git history only when older provenance is required

## Authority

- Missing project facts are unknown; a generated scaffold is not evidence of behavior.
- Business and technical claims require inspected repository evidence or an explicit user decision.
- `openspec/specs/` contains normative current observable behavior, not a duplicate of this integrated explanation.
- A task is incomplete while its implementation and affected project handoff or OpenSpec lifecycle layers disagree.
